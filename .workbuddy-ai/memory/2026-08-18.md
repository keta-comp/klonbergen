## Mobile admin login crash — `t is not defined` (FIXED)
Root cause: `HallAdminDashboard.tsx` `AdminHome` was a MODULE-SCOPE helper component (lines ~224-232) that used `t('admin.sidebar.brand')`, but `t` was only declared inside the `HallAdminDashboard` component body. The index/bosh-sahifa route (post-login landing) rendered `AdminHome` → `ReferenceError: t is not defined` (exact crash in screenshot, `HallAdminDashboard-*.js at gn/yp`). Fixed by adding `const { t } = useTranslation();` inside `AdminHome` (i18n-architecture-correct; no global introduced).

Audit caught a SIBLING bug same class: `SuperAdminDashboard.tsx` module-scope sub-pages (`TariflarPage`, `TolovlarPage`, `BildirishnomalarPage`, `ActivityPage`) used `formatNumber/Date/DateTime(locale, …)` with no `locale` in scope → would throw `ReferenceError: locale is not defined`. Fixed by `const { t, locale } = useTranslation();` in each. Also fixed type-only errors: `VenueCard` called `formatLocaleDate(value)` with 1 arg (missing `locale`); `ArchiveCard`/`ArchiveDetailPage` passed `string` `locale` from `useParams()` to `Locale`-typed format fns (typed `as Locale`); added `seed_default_plans` to generated `Functions` type in `src/integrations/supabase/types.ts`.

**Critical tsc gotcha:** `tsc --noEmit` against the ROOT `tsconfig.json` is a NO-OP (root has `files:[]` + project `references`, non-build mode compiles nothing → silently 0 errors). The real check is `./node_modules/.bin/tsc -p tsconfig.app.json --noEmit`. After fixes: TSC_OK (exit 0), `vite build` → ✓ built (10.10s) to `.vite-build-tmp` then `cp -r` into `dist/` (rm/emptyOutDir blocked by safe-delete shim). ErrorBoundary (`src/components/common/ErrorBoundary.tsx`) confirmed to SURFACE error.message+stack (not hide).

## Hall Admin sidebar — raw i18n keys showing instead of names (FIXED)
User screenshot (Russian locale, `Сегодняшняя свадьба` header): sidebar showed raw keys `admin.nav.bosh-sahifa`, `bannerlar`, `dastur`, `taomlar`, `artistlar`, `kelin-kuyov`, `suratlari`, `musiqa` (only `qr`, `rsvp`, `archive` rendered correctly).
Root cause: `src/components/admin/AdminSidebar.tsx` `CURRENT_ITEMS[*].to` uses dashed ids (`bosh-sahifa`, `bannerlar`, …) and renders `t(`admin.nav.${it.to}`)`. Locale files only had the underscore variants (`home`, `banners`, `program`, `menu`, `artists`, `couple`, `photos`, `music`). `qr`/`rsvp`/`archive` worked by coincidence (identical in both id forms). Renaming sidebar `to` values would break URL routing (`buildPath` + `active` match), so added 8 dashed alias keys to `admin.nav` in all 4 locales (uz/ru/en/kaa) pointing to the existing translations.
Verified: JSON valid all 4, `tsc --noEmit` EXIT 0, `vite build --outDir dist-nav-fix` EXIT 0.
