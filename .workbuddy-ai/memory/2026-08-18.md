## Mobile admin login crash — `t is not defined` (FIXED)
Root cause: `HallAdminDashboard.tsx` `AdminHome` was a MODULE-SCOPE helper component (lines ~224-232) that used `t('admin.sidebar.brand')`, but `t` was only declared inside the `HallAdminDashboard` component body. The index/bosh-sahifa route (post-login landing) rendered `AdminHome` → `ReferenceError: t is not defined` (exact crash in screenshot, `HallAdminDashboard-*.js at gn/yp`). **Critical tsc gotcha:** `tsc --noEmit` against the ROOT `tsconfig.json` is a NO-OP (root has `files:[]` + project `references`, non-build mode compiles nothing → silently 0 errors).
