## Vowly Super Admin — full button/menu functional audit (Request: "barcha tugmalarni tekshirib chiq")
Audited every button/menu in Super Admin and fixed real bugs:

1. **Archived halls invisible** → archived filter + Restore flow were dead. `SuperAdminDashboard` called `useAdminHalls()` (default excludes archived). Fixed: `useAdminHalls({ includeArchived: true })`; stats still skip archived, filters work.
2. **Pay button only on expired** → halls with no subscription could never be activated. `VenueCard` now shows "To'lovni qabul qilish" for any non-archived hall (amber when expired, neutral otherwise).
3. **Support card button did nothing** → wired to `mailto:support@vowly.uz` (placeholder address — user can change).
4. **`onManage` fragile** → used `location.pathname` parse; switched to `locale` from `useTranslation()` for robust `/:locale/admin/bosh-sahifa?hall=` nav (works via LegacyRedirect anyway).
5. **i18n `common.openMenu`/`common.close` missing at root** → `t('common.openMenu')` fell back to raw key (aria-labels on hamburger + modal X). Root cause: `lookup()` resolves dotted keys from ROOT dict, but `common` only existed nested. Added root-level `common` group with both keys in uz/en/ru/kaa. Removed mistaken nested insertion via Node script.
